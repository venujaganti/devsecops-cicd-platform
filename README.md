# DevSecOps CI/CD Platform

A complete DevSecOps CI/CD platform built using modern development,
containerization, orchestration, automation, security, infrastructure
as code, and monitoring technologies.

## Technologies

- React
- FastAPI
- PostgreSQL
- Podman
- Kubernetes
- Jenkins
- Git
- GitHub
- GitHub Actions
- Trivy
- SonarQube
- Terraform
- AWS
- Prometheus
- Grafana
